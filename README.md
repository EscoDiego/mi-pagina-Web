# Portafolio personal — Diego César Escobar Martínez

**Programador junior enfocado en desarrollo web.** Este sitio presenta mi experiencia, formación y proyectos en una interfaz inspirada en una consola arcade retro, sin perder acceso directo al CV y a los datos de contacto.

**Ver en línea:** https://escodiego.github.io/mi-pagina-Web/

## Qué encontrarás

- **Sobre mí:** experiencia en desarrollo web con C#, .NET y tecnologías frontend.
- **Skills y educación:** herramientas que uso y formación completada o en curso.
- **Proyectos:** demos y una breve explicación de cada trabajo.
- **Contacto:** correo, LinkedIn, GitHub, WhatsApp y CV descargable.
- Interfaz en **español e inglés**, navegación por niveles y sonido opcional que comienza tras una interacción.

## Tecnologías

HTML5, CSS3 y JavaScript sin framework. El audio retro se genera con la Web Audio API. El sitio incluye diseño responsive, navegación por teclado y estilos para `prefers-reduced-motion`.

## Ejecutar localmente

Clona el repositorio y abre `index.html` en un navegador. No requiere instalación ni proceso de compilación. La foto y el CV están integrados en el archivo HTML; las tipografías se cargan desde Google Fonts cuando hay conexión.
